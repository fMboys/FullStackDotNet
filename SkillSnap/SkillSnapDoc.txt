SkillSnap Project Documentation
Project Summary

SkillSnap is a full-stack portfolio and skills management application built using ASP.NET Core Web API, Entity Framework Core, ASP.NET Identity, and Blazor. The application allows users to register, authenticate, manage their professional profiles, showcase projects, and organize technical skills through a modern web interface.

The backend provides RESTful API endpoints for authentication, project management, and skill management, while the Blazor frontend delivers an interactive user experience. JWT authentication secures API access, and state management preserves user information across components during a session.

Challenges Encountered
Authentication Configuration

Integrating ASP.NET Identity with JWT authentication required careful configuration of:

UserManager
SignInManager
Token generation
Middleware registration
Resolution

Tested authentication endpoints independently using Swagger and validated JWT claims.

State Management

Passing data between components became increasingly difficult as additional features were added.

Resolution

Implemented a centralized UserSessionService using the scoped service pattern.

Performance Optimization

Database queries were being executed on every request.

Resolution

Implemented memory caching and measured improvements using Stopwatch instrumentation.

Conclusion

SkillSnap successfully demonstrates a modern full-stack application architecture using Blazor, ASP.NET Core, Entity Framework Core, Identity, JWT authentication, caching, and state management. The project provides a secure and scalable foundation for a developer portfolio platform while showcasing best practices in API design, user authentication, performance optimization, and component-based UI development.
